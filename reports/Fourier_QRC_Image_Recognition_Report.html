1. 背景与问题定义

1.1 核心问题

目标：利用傅里叶分解（Fourier Decomposition）提取图像的频域信息，将其与量子储备池计算（Quantum Reservoir Computing, QRC）结合，实现高效、可解释的图像识别。

1.2 研究动机

  • 频域信息的互补性：傅里叶频谱天然地分离了图像的全局结构（低频频谱）、纹理细节（中频频谱）和边缘/噪声（高频频谱）。这与CNN学习的空间特征形成互补。
  • QRC 的固定动态特性：QRC使用固定的量子动力学作为特征映射，避免了梯度训练中的贫瘠高原（Barren Plateaus）。但其输入编码方案直接决定了模型的表达力上限。
  • 理论统一性：Xiong et al. (2025) 证明 QELM 的预测可精确分解为傅里叶级数——频域特征与量子储备池之间存在深层的数学对应关系。
  • 新兴机会：傅里叶预处理 + 储备池计算的组合在文献中几乎未被研究，代表一个具有探索价值的方向。

1.3 原始设想

图像→ FFT/DCT→ 频段分割→ 8D 低频+ 8D 中频+ 8D 高频→ QRC 编码→ 特征拼接→ 线性读出

以及替代方案：辅助记忆比特多步输入、频域结构驱动QRC演化。

2. 核心方法调研

2.1 QRC / QELM 理论基础

QELM 流水线

阶段描述
编码 (Encoding)经典数据 x → 量子态 ρ(x) = U(x)ρ₀U†(x)，通过参数化酉算子
储备池 (Reservoir)固定量子动力学演化，通常由 XY 模型、Ising 模型或交错ZZ相互作用实现
测量 (Measurement)多项式可观测集 {Oₖ}，提取期望值 ⟨Oₖ⟩
读出 (Readout)线性回归（Ridge / 伪逆），仅此层可训练
🔬 关键理论发现 (Xiong et al., 2025)：
QELM输出 f(x) 可精确表示为有限傅里叶级数：
f(x) = Σ_{ω∈Ω} a_ω · exp(iωx)
其中：频率集合 Ω 由编码哈密顿量的特征值差决定；傅里叶系数 a_ω 由初始态、储备池和测量共同决定。
这一发现表明：频域信息的引入与QRC的数学结构天然相容。

由于 QRC 的线性读出层本质上是一个浅层分类器，频域特征的引入有望带来类似的显著增益。

3. 方案 A：频段分解 + 多通道 QRC 拼接

3.1 方案描述

可行 推荐实验

将图像的2D-FFT频谱按半径划分为三个频段，每个频段降维到8维特征，分别送入独立的QRC单元，最后拼接三个QRC的输出特征进行线性分类。

3.2 详细流程

28×28 图像→ 2D FFT→ 频谱幅度→
🔵 低频 (r ≤ 4)
全局结构/光照
PCA → 8D
🟡 中频 (4 < r ≤ 8)
纹理/形状
PCA → 8D
🔴 高频 (8 < r ≤ 14)
边缘/细节
PCA → 8D
QRC₁ (4Q)→ QRC₂ (4Q)→ QRC₃ (4Q)→ 拼接 3×(2⁴−1)→ Ridge 分类器

3.3 QRC 编码设计

# 每个8D频段特征 → 4量子比特 QRC
# 编码: angle encoding (RY rotation per feature, 2 features per qubit)
for i in range(4):
    qml.RY(features[2*i], wires=i)
    qml.RZ(features[2*i+1], wires=i)

# 储备池: XY模型固定演化
H_res = Σᵢⱼ Jᵢⱼ(σˣᵢσˣⱼ + σʸᵢσʸⱼ)   # Jᵢⱼ ~ N(0, 0.3²)

# 测量: 所有Pauli-Z期望值 (2⁴−1=15维)
measurements = [qml.expval(qml.PauliZ(i)) for i in range(4)]
# + 2-qubit correlations for enhanced expressivity

3.4 理论依据与风险

优势风险
✅ 频段分离提供解耦的特征空间⚠️ PCA降维可能损失相位信息
✅ QRC的固定动态不需要梯度训练⚠️ 4量子比特的频段编码可能表达能力不足
✅ 多通道架构天然可并行化⚠️ 频率半径阈值需要网格搜索
✅ 与FreqNet/TANet的设计理念一致⚠️ 三个独立QRC缺少跨频段交互

4. 方案 B：辅助记忆比特 + 多步序贯输入

4.1 方案描述

中等风险 有理论基础

不将三个频段并行输入，而是将频段信息按时间顺序依次输入同一个QRC，利用储备池的记忆效应累积多尺度频域信息。同时引入辅助记忆量子比特来增强长期记忆。

4.2 时序化方案

# 时间步1: 输入低频8D特征
state₁ = QRC_reservoir(encode(LF_8D), initial_state=|0⟩)

# 时间步2: 输入中频8D特征（储备池保留t1的记忆）
state₂ = QRC_reservoir(encode(MF_8D), initial_state=state₁)

# 时间步3: 输入高频8D特征
state₃ = QRC_reservoir(encode(HF_8D), initial_state=state₂)

# 输出: 读取最终状态 + 辅助记忆比特
output = concat([measure(state₃), memory_qubits])

4.3 辅助记忆比特设计

方案 B1: 量子寄存器记忆

额外分配 M=2 个"记忆量子比特"，在每一步结束时将部分储备池状态通过受控门写入记忆比特。

# 每步结束时:
for i in range(M):
    qml.CRY(α * state_measurement(active_qubit), active_qubit, memory_qubit[i])

方案 B2: 时间延迟嵌入

借鉴经典RC的 delay embedding 技术，将前k步的测量结果显式拼接为"历史向量"。

# 输出特征 = [当前测量 | t-1测量 | t-2测量 | 记忆比特]
output_features = concat([O_current, O_prev1, O_prev2, mem_bits])

4.4 理论依据

  • Delay-based RC 的记忆容量：Köster et al. (2020) 证明延迟耦合储备池在 τ ≈ 1.6T 时记忆最优，且存在特定的"可回忆时间步"共振窗口。
  • 序列记忆任务：线性激活储备池可在宽耦合范围内实现近乎完美的延迟重建（记忆 ≥20步）。
  • Long-Short Term TDR (2026)：长时间延迟模块 + 短期选择性遗忘模块的组合架构超越了Deep-ESN等基线。
  • 量子记忆：量子Zeno效应或离散时间晶体 (arXiv:2508.15230) 可用于增强量子态的持久性。

4.5 优势与风险

优势风险
✅ 天然跨频段交互（同一QRC处理所有频段）⚠️ 量子噪声导致的退相干可能破坏记忆
✅ 参数量更少（仅一个QRC）⚠️ 时序化增加了推理时间 (3×步骤)
✅ 与 delay-based RC 理论体系对接⚠️ 频段间的顺序依赖可能不合理（HF不应依赖于MF）
✅ 辅助记忆比特有量子信息理论基础⚠️ 量子储备池的记忆容量尚无严格下界

5. 方案 C：傅里叶结构信息 + QRC 演化

5.1 方案描述

探索性 理论新颖

不直接使用频域特征作为QRC的输入编码，而是利用傅里叶分解提取的结构信息（如相位谱、频谱对比度、方向性特征）来调制QRC的演化哈密顿量参数，使储备池动力学自适应于输入图像的结构特性。

5.2 核心思想

图像 → FFT→ 结构特征提取→ 谱各向异性→ 耦合矩阵 J(θ)
图像 → FFT→ 结构特征提取→ 相位一致性→ 局域场 h(φ)

5.4 进化式储备池（EvoESN 量子类比）

🔗 与经典方法对接：Basterrech & Rubino (2022) 的 EvoESN 证明了在 DCT 域优化储备池权重的有效性。
量子类比：方案C可以视为在该工作基础上的量子推广 —— 频域结构特征 不是被优化，而是由输入图像的傅里叶谱自适应决定。

5.5 自适应哈密顿量设计

# 提取结构参数
anisotropy = compute_anisotropy(fft_magnitude)       # ∈ [0, 1]
decay_rate  = compute_spectral_decay(fft_magnitude)   # ∈ [0.5, 2.5]
entropy     = compute_spectral_entropy(fft_magnitude)  # normalized

# 调制QRC哈密顿量
J_horizontal = J_base * (1 + β * anisotropy)
J_vertical   = J_base * (1 - β * anisotropy)
interaction_strength = J_max * (1 - decay_rate / 2.5)
evolution_time = T_base * entropy

# QRC演化
H = build_XY_hamiltonian(J_horizontal, J_vertical, interaction_strength)
evolved_state = expm(-1j * H * evolution_time) @ initial_state

# === fourier_qrc_pipeline.py ===
"""傅里叶分解 + QRC 图像识别完整流水线"""

import numpy as np
import torch
import torch.fft
import pennylane as qml
from sklearn.decomposition import PCA
from sklearn.linear_model import RidgeClassifier
from sklearn.metrics import accuracy_score, f1_score
from torchvision import datasets, transforms

# ========== 模块1: 傅里叶频段分解 ==========
class FourierBandSplitter:
    """将图像FFT频谱分解为低/中/高三个频段"""

    def __init__(self, img_size=28, bands=[(0,4), (5,8), (9,14)]):
        self.img_size = img_size
        self.bands = bands  # (r_min, r_max) per band
        self._build_masks()

    def _build_masks(self):
        """构建频段掩膜"""
        Y, X = np.ogrid[:self.img_size, :self.img_size]
        cy, cx = self.img_size // 2, self.img_size // 2
        self.radius = np.sqrt((X - cx)**2 + (Y - cy)**2)

        self.masks = []
        for r_min, r_max in self.bands:
            mask = (self.radius >= r_min) & (self.radius <= r_max)
            self.masks.append(mask)

    def extract(self, image):
        """输入: (H, W) 灰度图像, 输出: [band1_mag, band2_mag, band3_mag]"""
        fft = torch.fft.fft2(image)
        fft_shifted = torch.fft.fftshift(fft)
        magnitude = torch.abs(fft_shifted)

        band_features = []
        for mask in self.masks:
            mask_t = torch.tensor(mask, dtype=torch.bool)
            band_mag = magnitude * mask_t
            band_features.append(band_mag)
        return band_features


# ========== 模块2: 频段编码 → QRC ==========
class BandQRC:
    """单频段的量子储备池编码器"""

    def __init__(self, n_qubits=4, n_features=8, n_layers=2):
        self.n_qubits = n_qubits
        self.n_features = n_features
        self.n_layers = n_layers
        self.pca = PCA(n_components=n_features)
        self._init_qnode()

    def _init_qnode(self):
        """构建Pennylane量子节点"""
        dev = qml.device("lightning.qubit", wires=self.n_qubits)

        @qml.qnode(dev)
        def circuit(features, J_matrix, h_field):
            # === 编码层 ===
            for i in range(self.n_qubits):
                qml.RY(features[2*i % len(features)], wires=i)
                qml.RZ(features[2*i+1 % len(features)], wires=i)

            # === 储备池层 (XY模型) ===
            for _ in range(self.n_layers):
                # XX + YY 相互作用
                for i in range(self.n_qubits):
                    for j in range(i+1, self.n_qubits):
                        qml.IsingXX(2 * J_matrix[i,j], wires=[i,j])
                        qml.IsingYY(2 * J_matrix[i,j], wires=[i,j])
                # 局域场
                for i in range(self.n_qubits):
                    qml.RZ(h_field[i], wires=i)

            # === 测量 ===
            return [qml.expval(qml.PauliZ(i)) for i in range(self.n_qubits)]

        self.circuit = circuit

    def fit_pca(self, X_band):
        """在训练集上拟合PCA"""
        # X_band: (N, H*W) 展平的频段幅度
        return self.pca.fit_transform(X_band)

    def transform(self, X_band, J_matrix, h_field):
        """将频段特征通过QRC映射"""
        X_pca = self.pca.transform(X_band)
        results = []
        for x in X_pca:
            # 归一化到 [0, π] 用于角度编码
            x_norm = np.pi * (x - x.min()) / (x.max() - x.min() + 1e-8)
            result = self.circuit(x_norm, J_matrix, h_field)
            results.append(result)
        return np.array(results)


# ========== 模块3: 全局频谱结构提取 (方案C) ==========
class SpectralStructureExtractor:
    """提取傅里叶频谱的结构特征"""

    def __init__(self, img_size=28):
        self.img_size = img_size

    def extract(self, image):
        """输入: (H,W), 输出: 结构特征向量"""
        fft = torch.fft.fft2(image)
        fft_shifted = torch.fft.fftshift(fft)
        mag = torch.abs(fft_shifted)

        # 1. 频谱各向异性
        h_energy = mag[:, mag.shape[1]//2].sum()
        v_energy = mag[mag.shape[0]//2, :].sum()
        anisotropy = (h_energy / (v_energy + 1e-8)).log().item()

        # 2. 谱衰减指数
        radial_energy = []
        for r in range(1, self.img_size//2):
            ring = mag[(torch.abs(Y_global - cy) <= 1) & ...]
            radial_energy.append(ring.sum().item())
        decay = np.polyfit(np.log(range(1, len(radial_energy)+1)),
                          np.log(np.array(radial_energy)+1e-8), 1)[0]

        # 3. 频谱熵
        mag_norm = mag / (mag.sum() + 1e-8)
        entropy = -(mag_norm * torch.log(mag_norm + 1e-8)).sum().item()

        # 4. 高低频能量比
        lf_energy = mag[:4, :4].sum() / (mag.sum() + 1e-8)

        return np.array([anisotropy, decay, entropy, lf_energy.item()])


# ========== 模块4: 完整流水线 ==========
class FourierQRCClassifier:
    """傅里叶分解 + QRC 图像分类器"""

    def __init__(self, img_size=28, n_qubits_per_band=4,
                 use_structural=True, use_delay_embed=False):
        self.splitter = FourierBandSplitter(img_size)
        self.qrc_bands = [
            BandQRC(n_qubits=n_qubits_per_band, n_features=8),
            BandQRC(n_qubits=n_qubits_per_band, n_features=8),
            BandQRC(n_qubits=n_qubits_per_band, n_features=8),
        ]
        self.use_structural = use_structural
        if use_structural:
            self.struct_extractor = SpectralStructureExtractor(img_size)
        self.use_delay_embed = use_delay_embed
        self.classifier = RidgeClassifier(alpha=1.0)

        # 初始化固定储备池参数
        self.J_matrices = [np.random.randn(4,4) * 0.3 for _ in range(3)]
        self.h_fields = [np.random.randn(4) * 0.1 for _ in range(3)]

    def fit(self, images, labels):
        """训练 (仅拟合PCA和线性分类器)"""
        N = len(images)
        all_band_features = [[], [], []]
        struct_features = []

        for img in images:
            bands = self.splitter.extract(img)
            for i, band in enumerate(bands):
                all_band_features[i].append(band.flatten())
            if self.use_structural:
                struct_features.append(self.struct_extractor.extract(img))

        # 对每个频段拟合PCA并做QRC映射
        qrc_outputs = []
        for i in range(3):
            X_band = np.array(all_band_features[i])
            self.qrc_bands[i].pca.fit(X_band)
            qrc_out = self.qrc_bands[i].transform(
                X_band, self.J_matrices[i], self.h_fields[i])
            qrc_outputs.append(qrc_out)

        # 拼接所有特征
        X_train = np.concatenate(qrc_outputs, axis=1)
        if self.use_structural:
            X_train = np.concatenate([X_train, np.array(struct_features)], axis=1)

        self.classifier.fit(X_train, labels)
        return self

    def predict(self, images):
        """推理"""
        all_band_features = [[], [], []]
        struct_features = []

        for img in images:
            bands = self.splitter.extract(img)
            for i, band in enumerate(bands):
                all_band_features[i].append(band.flatten())
            if self.use_structural:
                struct_features.append(self.struct_extractor.extract(img))

        qrc_outputs = []
        for i in range(3):
            X_band = np.array(all_band_features[i])
            qrc_out = self.qrc_bands[i].transform(
                X_band, self.J_matrices[i], self.h_fields[i])
            qrc_outputs.append(qrc_out)

        X_test = np.concatenate(qrc_outputs, axis=1)
        if self.use_structural:
            X_test = np.concatenate([X_test, np.array(struct_features)], axis=1)

        return self.classifier.predict(X_test)

def main():
    # 加载 MNIST
    transform = transforms.Compose([
        transforms.ToTensor(),
        transforms.Normalize((0.1307,), (0.3081,))
    ])
    train_set = datasets.MNIST('./data', train=True, download=True,
                                transform=transform)
    test_set = datasets.MNIST('./data', train=False, transform=transform)

    # 采样 (QRC模拟开销大)
    n_train, n_test = 2000, 500
    X_train = train_set.data[:n_train].float() / 255.0
    y_train = train_set.targets[:n_train].numpy()
    X_test = test_set.data[:n_test].float() / 255.0
    y_test = test_set.targets[:n_test].numpy()

    # 训练
    model = FourierQRCClassifier(use_structural=True)
    model.fit(X_train, y_train)

    # 评估
    y_pred = model.predict(X_test)
    acc = accuracy_score(y_test, y_pred)
    f1 = f1_score(y_test, y_pred, average='macro')
    print(f"Accuracy: {acc:.4f}, F1: {f1:.4f}")

    return model, acc


if __name__ == "__main__":
    main()

# === fourier_qrc_bloqade.jl ===
using Bloqade
using LinearAlgebra

"""
利用 Bloqade 模拟基于中性原子的量子储备池。
中性原子的Rydberg阻塞效应天然提供 Ising 型相互作用，
适合作为 QRC 的物理储备池。
"""

function build_rydberg_qrc(n_qubits::Int, features::Vector{Float64};
                          blockade_radius::Float64=8.5,
                          evolution_time::Float64=2.0)
    # 1D 原子链, 间距 ~6μm
    atoms = [(i * 6.0, 0.0) for i in 0:(n_qubits-1)]

    # 编码: 频域特征 → 原子失谐图案
    # 每个原子获得独立的失谐参数 δᵢ = f(features)
    detunings = features[1:n_qubits] .* 2π .* 10.0  # MHz scale

    # Rydberg哈密顿量
    h = rydberg_h(atoms;
                  Ω=2π*1.5,           # Rabi频率
                  Δ=detunings,        # 特征编码的失谐
                  blockade_radius=blockade_radius)

    # 演化
    state = zero_state(n_qubits)
    prob = SchrodingerProblem(state, evolution_time, h)

    # 模拟
    emulate!(prob)

    # 测量: 每个原子的Rydberg占据概率
    densities = [rydberg_density(prob, i) for i in 1:n_qubits]
    return densities
end

# 使用示例
features = rand(8) .* π  # 模拟的8D频段特征
result = build_rydberg_qrc(8, features)
println("QRC outputs: ", result)
