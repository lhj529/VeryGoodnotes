2. 电力市场出清问题的数学本质

2.1 业务定义

日前或日内电力市场出清，本质上是在给定市场规则、机组约束、网络约束和负荷/新能源预测的条件下，决定哪些机组开机、哪些报价被接受、每个时段的发电出力如何分配、备用如何配置，并据此形成出清电量与电价。标准框架分解为三个子问题：

SCUC
安全约束机组组合
→
SCED / DC-OPF
安全约束经济调度
→
价格形成
LMP / 分区电价

2.2 标准优化模型（最小化系统成本）

min Σt∈T [ Σi∈G ( Ci(Pi,t) + CiNLui,t + SUiyi,t + SDizi,t ) + Σr∈R CrresRr,t ]

其中：

  • ui,t ∈ {0,1} — 机组开停机状态（离散变量，量子层核心）
  • yi,t, zi,t ∈ {0,1} — 启动/停机动作
  • Pi,t — 连续出力（经典层求解）
  • Rr,t — 备用配置

2.3 六大约束体系

约束类型数学表达量子/经典归属
① 功率平衡 Σi Pi,t + PtRES = Dt 经典层（通过罚项可部分入量子）
② 出力上下限 Piminui,t ≤ Pi,t ≤ Pimaxui,t 量子层编码 + 经典层校核
③ 启停逻辑 ui,t − ui,t−1 = yi,t − zi,t 量子层（QUBO逻辑约束）
④ 爬坡约束 −RDi ≤ Pi,t − Pi,t−1 ≤ RUi 经典层为主，量子层可加罚项
⑤ 最小开/停机时间 Στ ui,τ ≥ UTi·yi,t 量子层（组合约束）
⑥ 网络安全约束 −Fℓmax ≤ Σn PTDFℓ,npn,t ≤ Fℓmax 严格归属经典层
⚠ 核心困难：该问题是一个大规模混合整数非线性规划 (MINLP)。以24时段×100台机组为例，仅二进制变量就达 2400+，组合空间呈指数膨胀。经典MILP求解器在严格限时、多场景、多块状报价场景下仍面临显著压力。

4. QAOA算法原理与QUBO/Ising编码

4.1 QAOA算法核心思想

量子近似优化算法 (Quantum Approximate Optimization Algorithm, QAOA) 是Farhi、Goldstone和Gutmann于2014年提出的变分量子算法，专为组合优化问题设计。其核心思想是：

  1. 将组合优化问题的目标函数编码为问题哈密顿量 HC（对角在计算基下）
  2. 交替施加问题演化 U(C,γ) = e−iγHC 和混合演化 U(B,β) = e−iβHB
  3. 通过经典优化器调节参数 (γ, β) 以最小化期望能量 ⟨HC⟩

4.2 QAOA量子电路结构

┌─────────────────────────────────────────────────────────┐ │ QAOA 深度 P 的电路 │ │ │ │ |0⟩ ──[H]──[U(C,γ₁)]──[U(B,β₁)]── ... ──[U(C,γₚ)]──[U(B,βₚ)]── 测量 │ |0⟩ ──[H]──[ ]──[ ]── ... ──[ ]──[ ]── 测量 │ ⋮ ⋮ ⋮ ⋮ ⋮ ⋮ ⋮ │ |0⟩ ──[H]──[ ]──[ ]── ... ──[ ]──[ ]── 测量 │ │ │ 问题哈密顿量 H_C = Σᵢ hᵢZᵢ + Σᵢⱼ JᵢⱼZᵢZⱼ │ │ 混合哈密顿量 H_B = Σᵢ Xᵢ │ └─────────────────────────────────────────────────────────┘

4.3 QUBO编码：从机组组合到二次无约束二进制优化

步骤1：定义二进制决策变量

x = [u1,1, u1,2, ..., u1,T, u2,1, ..., uN,T] ∈ {0,1}N×T

步骤2：将约束转化为二次罚项

目标函数（成本）：
Hcost(x) = Σi,t [Aiui,t + SUi·ui,t(1−ui,t−1)]

功率平衡罚项（引入slack变量后）：
Hbalance(x) = λ1Σt (Σi Piminui,t + st − Dt)²

启停逻辑罚项：
Hlogic(x) = λ2Σi,t (ui,t − ui,t−1 − yi,t + zi,t)²

最小开停机罚项：
HminUp/Down(x) = λ3Σi,t [max(0, UTi·yi,t − Στui,τ)]²

步骤3：总QUBO哈密顿量

H(x) = Hcost(x) + λ1Hbalance(x) + λ2Hlogic(x) + λ3HminUp/Down(x) + λ4Hramp(x) + λ5Hreserve(x)

其中 λj 为罚因子，需要在约束满足度与目标函数优化之间仔细调参。

4.4 Ising自旋变换

将 {0,1} 变量转换为 {+1,−1} 自旋变量，以适配标准QAOA框架：

zi = 2xi − 1,   xi = (zi + 1)/2
HIsing(z) = Σi hiZi + Σi<j JijZiZj + const

4.5 Slack变量技巧（Koretsky et al., 2021）

不等式约束（如出力上下限）通过引入辅助连续slack变量转化为等式约束后再平方罚入QUBO：

Piminui ≤ Pi ≤ Pimaxui
↓ 引入 si,1, si,2 ≥ 0
Pi − si,1 − Piminui = 0,   Pi + si,2 − Pimaxui = 0
↓ 平方罚入目标函数
Hpenalty = λ Σi [(Pi − si,1 − Piminui)² + (Pi + si,2 − Pimaxui)²]

5. 解耦策略：ADMM、Benders与拉格朗日松弛

电力出清问题的核心挑战在于离散变量与连续变量强耦合。三种主流解耦策略各有优劣：

5.1 ADMM解耦（推荐首选）

核心论文：QAOA-based Day-ahead Clearing Model for Electricity Spot Market (IEEE 2024)

ADMM (Alternating Direction Method of Multipliers) 将原始MILP分解为两个子问题交替求解：

┌──────────────────────────────────────────────────────────────────┐ │ ADMM 量子-经典解耦框架 │ │ │ │ 原始问题: min f(x, z) s.t. g(x)≤0, h(z)≤0, Ax+Bz=c │ │ ↓ ADMM分解 │ │ ┌─────────────────────┐ ┌─────────────────────┐ │ │ │ 离散子问题 (x) │ ←───→ │ 连续子问题 (z) │ │ │ │ u, y, z, b, r │ ADMM │ P, R, F, LMP │ │ │ │ ∈ {0,1}^n │ 乘子 │ ∈ ℝ^m │ │ │ │ │ │ │ │ │ │ ▸ QAOA求解 │ │ ▸ GUROBI/CPLEX │ │ │ │ ▸ QUBO/Ising编码 │ │ ▸ SCED/DC-OPF │ │ │ └─────────────────────┘ └─────────────────────┘ │ │ │ │ ADMM增广拉格朗日: │ │ L_ρ(x,z,λ) = f(x)+g(z) + λᵀ(Ax+Bz−c) + (ρ/2)‖Ax+Bz−c‖² │ │ │ │ 迭代: xᵏ⁺¹ = argmin L_ρ(x, zᵏ, λᵏ) ← QAOA │ │ zᵏ⁺¹ = argmin L_ρ(xᵏ⁺¹, z, λᵏ) ← 经典优化器 │ │ λᵏ⁺¹ = λᵏ + ρ(Axᵏ⁺¹ + Bzᵏ⁺¹ − c) ← 乘子更新 │ └──────────────────────────────────────────────────────────────────┘

5.2 3-Block ADMM变体（Mahroo & Kargarian, 2022）

将问题进一步分解为三个block，更细粒度地利用量子能力：

Block变量求解器
Block 1 (Quadratic)yi, pi (连续)经典 IPOPT / Pyomo
Block 2 (QUBO)zi (二进制/Ising)QAOA via Qiskit
Block 3 (Unconstrained Quadratic)ri (辅助变量)经典

5.3 Benders分解方案

Benders分解将问题分为主问题（Master Problem, 离散决策）和子问题（Subproblem, 连续校核）：

主问题 (MP) — 量子层:
minu∈{0,1} cᵀu + θ
s.t. θ ≥ αkᵀu + βk (Benders cuts)

子问题 (SP) — 经典层:
给定 û，求解SCED/DC-OPF，生成： · 可行性割 (feasibility cut)：修复不可行û
· 最优性割 (optimality cut)：改进目标下界估计

Benders方案的优势在于主问题规模高度紧凑（仅含离散变量），最适合量子硬件qubit受限的场景。

5.4 拓扑分解：PSI-QAOA（Zhou et al., 2025）

最新方案利用电力系统拓扑结构将大规模UC分解为多个小规模子问题，每个子问题并行求解：

原始问题 (N×T维) → 拓扑检测 → 解耦为 K 个子问题 (nk×T维, nk << N)

在IEEE 39-bus (10 units, 60 qubits)、118-bus (54 units, 81 qubits)、300-bus (69 units, 52 qubits) 上实现1–2个数量级的性能提升。电网越稀疏，效果越好。

5.5 三种解耦策略对比

策略量子qubit要求收敛速度理论保证推荐场景
ADMM 中等 中等（需调ρ） 凸情形有保证 ⭐ 首选推荐（日前出清）
Benders 低（主问题紧凑） 快（割快速收紧） MILP标准保证 qubit极度受限时
拓扑分解 最低（子问题小） 极快（并行） 稀疏网络有保证 大规模稀疏电网

Pgminug,t ≤ Pg,t ≤ Pgmaxug,t,   ∀g,t

(3) 启停逻辑约束：
yg,t − zg,t = ug,t − ug,t−1,   ∀g,t
yg,t + zg,t ≤ 1,   ∀g,t

(4) 最小开机时间约束：
Στ=max(1, t−UTg+1)t yg,τ ≤ ug,t,   ∀g,t ≥ UTg

(5) 最小停机时间约束：
Στ=max(1, t−DTg+1)t zg,τ ≤ 1 − ug,t,   ∀g,t ≥ DTg

(6) 爬坡约束：
−RDg ≤ Pg,t − Pg,t−1 ≤ RUg,   ∀g,t

(7) 旋转备用约束：
Σg Rg,tup ≥ SRtreq,   Rg,tup = min(Pgmaxug,t − Pg,t, RUg·τ)

−Fℓmax ≤ Σn PTDFℓ,n·(Σg∈nPg,t + Pn,tRES − Dn,t) ≤ Fℓmax,   ∀ℓ,t

9. 关键论文详细解读

🔴 Paper 1: QAOA-based Day-ahead Clearing Model for Electricity Spot Market
IEEE, Guangzhou, Sep 2024 · 已下载本地

核心贡献：首次提出ADMM+QAOA的混合框架解决日前现货市场出清。将SCUC通过ADMM解耦为离散子问题(QAOA)和连续子问题(经典求解器)，在IEEE 39-bus系统验证。

方法亮点：ADMM乘子实现离散/连续层的信息交换；QAOA处理机组启停；经典SCED完成调度、潮流和LMP计算。

验证结果：IEEE 39-bus系统上获得可行机组组合、调度和节点边际电价，证明了混合架构的可行性。

🔴 Paper 2: Adapting Quantum Approximation Optimization Algorithm (QAOA) for Unit Commitment
Koretsky et al., IEEE QCE 2021 · arXiv:2110.12624 · 已下载本地

核心贡献：第一个将QAOA应用于UC问题的完整实现。使用slack变量技巧将不等式约束转化为QUBO罚项，在Qiskit上实现P=1和P=2的QAOA。

技术细节：

  • 双循环架构：外层SciPy Nelder-Mead优化(γ,β)和连续变量，内层Qiskit QAOA模拟
  • 目标函数 = 原始成本 + λ₁(功率平衡罚项) + λ₂(最小功率罚项) + λ₃(最大功率罚项)
  • 关键发现：P=2相比P=1显著提高了近优解的概率

局限性：当前仅适用于小型系统（6-10台机组），量子优势预计在数百台机组时显现。

🔴 Paper 3: Hybrid Quantum-Classical Unit Commitment
Mahroo & Kargarian, IEEE TPEC 2022 · arXiv:2201.03701 · 已下载本地

核心贡献：提出3-Block ADMM分解框架，将UC分解为Quadratic、QUBO、Unconstrained Quadratic三个子问题。

10-unit系统测试结果：QAOA (P=2, 100次max iteration) 在正确更新变分参数时能恢复与经典求解器相同的解。

关键经验：变分参数的初始化和更新策略至关重要；ADMM的罚参数ρ需要与QUBO的罚参数λ协调。

🟡 Paper 4: A hybrid classical-quantum approach to highly constrained Unit Commitment problems
Salgado, Sequeira, Santos · arXiv:2412.11312, Dec 2024 · 已下载本地

核心贡献：首次在混合量子-经典UC中包含旋转备用约束。使用warm-start QAOA优化，解的质量在经典参考解的5.1%以内，且具有多项式时间复杂度。

技术进步：warm-start技术利用经典松弛解初始化QAOA参数，显著提高了收敛速度和解质量。

🟣 Paper 5: Problem-Structure-Informed QAOA for Large-Scale UC with Limited Qubits
Zhou, Zhu, Zhu, Bu · iEnergy 2025 · arXiv:2503.20509 · 已下载本地

核心贡献：利用电力系统拓扑结构将大规模UC分解为并行可解的小子问题，突破qubit限制。

10.3 关键风险与缓解

聚焦多场景、短时限、多候选需求场景，而非一对一速度竞赛
风险影响缓解措施
Qubit数量不足无法编码全规模问题拓扑分解(PSI-QAOA)、机组聚类、仅编码最关键的离散变量
QAOA电路深度受限（噪声）解质量下降Warm-start QAOA、误差缓解、P渐进加深（从P=1开始验证）

经典MILP仍主导量子方案难以证明价值

11. 结论与展望

11.1 核心结论

  1. 切入点精准：QAOA在电力出清中最有价值的切入点是SCUC中的离散组合优化——机组启停、块状报价接受、备用组合选择。不是替代整个出清引擎，而是增强其组合搜索能力。
  2. 架构成熟：混合量子-经典三层架构（经典预处理 → 量子离散主问题 → 经典连续校核）是当前技术条件下的最优路线，已被IEEE 39-bus、57-bus、118-bus、300-bus系统逐一验证。
  3. 解耦是关键：ADMM是目前最成熟的解耦框架（IEEE 2024论文），Benders适合qubit极度受限场景，拓扑分解(PSI-QAOA 2025)在大规模稀疏电网中展现1-2个数量级的优势。
  4. 当前技术水平：在小型系统(IEEE 39-bus, ~10 units)上已实现原型验证；中型系统(IEEE 118-bus, ~54 units)上通过拓扑分解可求解；真实全规模市场尚未被超越。
  5. 工程定位：短期作为候选方案生成器或warm-start增强模块，中期作为主问题求解器，长期才有望成为出清核心组件。
