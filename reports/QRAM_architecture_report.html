调研动机与研究背景

量子随机存取存储器（Quantum Random Access Memory, QRAM）被广泛认为是实现量子计算实用优势的关键瓶颈组件。与经典 RAM 允许 CPU 快速检索指定地址的数据类似，QRAM 使得量子处理单元（QPU）能够在叠加态中访问经典（或量子）数据：

\[ U_{\text{QRAM}} \sum_x \alpha_x |x\rangle_A |0\rangle_B = \sum_x \alpha_x |x\rangle_A |D_x\rangle_B \]

QRAM 的量子查询操作：地址寄存器 A 处于叠加态，输出总线上出现对应数据的叠加

这一能力对大量量子算法至关重要——包括量子线性代数、量子机器学习、量子化学模拟、Shor 算法的现代变体、Grover 搜索、碰撞查找和格基密码分析等。然而，QRAM 的物理实现一直是量子计算领域最具争议和挑战性的问题之一。

中科酷原（中国科学院精密测量科学与技术创新研究院孵化的量子计算公司）拥有国内领先的中性原子量子计算平台。其「汉原」系列量子计算机的核心技术栈——光学镊阵列、魔幻光强阱、里德堡阻塞门、光纤阵列寻址架构和相干原子转移——恰好为 QRAM 的物理实现提供了独特且极具优势的硬件基础。

核心调研问题：如何利用中科酷原的中性原子量子计算平台，设计并实现高效、可扩展、噪声鲁棒的 QRAM 架构？

本报告基于对 20+ 篇 QRAM 文献和中科酷原平台 14 篇核心论文的系统调研，提出三种可行方案，并给出综合推荐架构。

QRAM 基础理论与架构总览

2.1 QRAM 的形式化定义

按照 Kuperberg (2024) 的分类法，量子存储器可根据两个维度分为四种类型：

经典访问 (CRA)量子访问 (QRA)
经典存储 (CM) CRACM（传统 RAM） QRACM（量子地址访问经典数据）
量子存储 (QM) CRAQM（可寻址量子比特） QRAQM（量子地址访问量子数据）

本报告主要关注 QRACM（Quantum Random Access Classical Memory），这是大多数量子算法所依赖的形式，也是实现难度相对较低的目标。定义如下：

\[ U_{\text{QRACM}}(T) |i\rangle |0\rangle = |i\rangle |T_i\rangle \] \[ \text{其中 } T \in \{0,1\}^N \text{ 为经典数据表，} i \text{ 为 } n=\log_2 N \text{ 位的地址} \]

QRACM 操作的核心包含两个子任务：(1) 路由（routing）——将输入地址信号分发到正确的物理存储单元；(2) 读出（readout）——从该单元提取数据并返回。路由通常被认为是更具挑战性的部分。

2.2 Bucket-Brigade 架构

Giovannetti, Lloyd 和 Maccone (GLM, 2008) 提出的 bucket-brigade（斗链式）架构是迄今为止最主流、研究最深入的 QRAM 架构。其核心思想是用一个由 \(2N-1\) 个量子路由器（router）构成的完全二叉树来路由地址和数据：

┌─────────────────────────────────────────────────────────┐
│              Bucket-Brigade QRAM 查询流程                  │
│                                                         │
│  地址 qubit: |a₀,a₁,a₂⟩  (n=3 → N=8 个存储单元)         │
│                                                         │
│         ┌───┐                    ← 根路由器 (第0层)       │
│         │ R │                                           │
│         └─┬─┘                                           │
│       ┌───┴───┐                                         │
│     ┌─┴─┐   ┌─┴─┐           ← 第1层 (2个路由器)          │
│     │ R │   │ R │                                       │
│     └─┬─┘   └─┬─┘                                       │
│   ┌───┴───┐ ┌───┴───┐     ← 第2层 (4个路由器)            │
│  ┌┴┐ ┌┴┐ ┌┴┐ ┌┴┐                                        │
│  │R│ │R│ │R│ │R│           ← 叶层 + N个存储单元          │
│  └┬┘ └┬┘ └┬┘ └┬┘                                        │
│  [D₀] [D₁] [D₂] [D₃] [D₄] [D₅] [D₆] [D₇]   ← 经典数据  │
│                                                         │
│  查询步骤 (深度 O(log N)):                                │
│  1. 地址注入: 逐位将地址 qubit 送入根路由器               │
│  2. 路由传播: 每个路由器根据控制态 |L⟩/|R⟩ 路由信号       │
│  3. 数据复制: 信号到达叶层后，复制对应数据                │
│  4. 逆路由: 沿原路返回，解纠缠路由器                      │
│                                                         │
│  路由器状态: |W⟩ (等待/空闲)  |L⟩ (左路由)  |R⟩ (右路由)  │
└─────────────────────────────────────────────────────────┘

Bucket-Brigade 的关键优势：

  • 查询深度：\(O(\log N)\)，指数级优于朴素方案的 \(O(N)\)
  • 噪声弹性：查询保真度仅随 \(O(\text{poly}\log N)\) 退化（而非 \(O(\text{poly} N)\)）——这是该架构最不平凡的特性
  • 可逆性：路由过程完全可逆，查询结束后树恢复到初始态（理想条件下）
  • 低激发率：每次查询只激发树中 \(O(\log N)\) 个路由器，其余保持在惰性 |W⟩ 态

硬件开销：虽然时间深度为 \(O(\log N)\)，但物理路由器数量为 \(O(N)\)（N个存储单元需要 N-1 个路由器）。这意味着 QRAM 的"芯片面积"与存储容量成线性关系，类似经典 RAM——这是所有已知 QRAM 方案面临的共性挑战。

2.3 Active vs Passive QRAM 之争

Jaques 和 Rattew (2025, Quantum) 的综述将 QRAM 方案分为两大类：

🔌 Active QRAM（电路型）

每次查询需要外部控制器对每个门操作进行干预。包括所有纯 Clifford+T 电路实现。

优点：兼容容错量子计算框架，可直接纠错

缺点：总控制成本 \(O(N)\)，机会成本巨大——控制硬件本身就可以并行运行经典算法

T-gate 开销：\(O(N)\) T 门 / \(O(N)\) 量子比特

⚡ Passive QRAM（硬件型）

查询信号注入后无需外部干预，通过物理哈密顿量的时间演化"弹道式"完成。

优点：理论上无控制开销，可实现真正的量子加速

缺点：需要近乎零噪声的物理元件；无法主动纠错；隐含着极其苛刻的物理假设

可行性：Jaques 认为现有提案均存在根本性缺陷

对中科酷原的启示：纯粹的被动 QRAM 在当前技术水平下不可行，而纯电路 QRAM 的机会成本过高。中科酷原的最佳路径是走"主动硬件 QRAM"的中间路线——利用物理层的天然噪声弹性（bucket-brigade 的 polylog 保真度缩放）结合适度的量子纠错，而非寄希望于完全无源的弹道计算。

2.4 QRAM 噪声弹性

Hann et al. (2021, PRX Quantum) 严格证明了 Bucket-Brigade QRAM 的噪声弹性定理，Lee/Mehta et al. (2024) 进一步扩展到更广泛的噪声模型：

噪声模型保真度缩放关键条件
局部非相干噪声 (Bernoulli) \(1-F \leq 4(\vartheta+1)(n+1) \in O(n^2)\) 单路由器误差率 \(\epsilon\)、三能级路由器
任意初始化误差 \(1-F \leq 4(\vartheta+1)(n+1)^2 \in O(n^3)\) 二能级路由器 + 查询倍增（query doubling）
空间关联误差 保持 polylog 缩放 关联范围有限
相干误差 polylog 缩放（但系数变大） 可通过 Pauli Twirling 转换
连续去极化噪声 \(1-F \propto \epsilon \cdot O(\log^2 N)\) \(\epsilon \lesssim 10^{-4}\) 时 N≤512 保真度 >95%

设计启示：Bucket-Brigade 的 polylog 噪声弹性使得我们可以在不依赖完全量子纠错的情况下，利用物理层保真度的适度提升来支持中等规模的 QRAM（N≈2¹⁰~2¹⁵，即 1KB~32KB）。这对于中科酷原当前 200-qubit 级别的平台来说是一个务实的目标。

3.3 平台瓶颈与 QRAM 特定挑战

  • 里德堡态寿命限制：里德堡态的自然寿命约 100-200 μs（n≈70），而 CZ 门时间约 1-5 μs，留给构成复杂路由器操作的时间窗口有限。但这对于 μs 级的 SWAP/CSWAP 路由操作已足够。
  • 原子加热：大量原子移动（QRAM 工厂需要频繁重排）会累积动能，最终导致原子逃逸。转移加热 <1 μK/周期可支持 500+ 周期，但工厂模式下需优化周期数。
  • 光镊阵列密度：当前间距 ~5.6 μm，受限于里德堡阻塞半径和光学分辨率。N=1024 的 QRAM 树需要 ~2000 个路由器原子，在二维阵列中占据约 50×40 的区域，需 3+ 层堆叠。
  • 双比特门保真度：当前光纤阵列平台双比特门保真度（0.98-0.99+）是 QRAM 查询保真度的主要瓶颈。每个查询涉及 O(n) 个路由操作，需要门保真度 ≥0.999 才能支持大规模 QRAM。

方案一：Resource-State QRAM（推荐方案）首选

论文：Cesa, Bernien & Pichler (2025) "Resource-State Quantum RAM for Fast and Error-Correctable Queries" (arXiv:2503.19172)

这是最直接针对中性原子平台设计的 QRAM 方案，作者来自因斯布鲁克大学/芝加哥大学，包含对中性原子阵列的详细实现蓝图。该方案是本次调研的核心推荐方案。

4.1 设计原理与 Clifford 查询协议

Resource-State QRAM 的核心创新在于将 QRAM 的复杂性完全外包给离线制备的资源态（resource state），而在线查询仅使用简单的 Clifford 操作和单量子比特 Pauli 测量（SQPM）：

\[ U_{\text{QRAM}} = V^{-1} W_D V \] \[ \underbrace{\text{非 Clifford}}_{V} \longrightarrow \underbrace{\text{Clifford 查询}}_{\text{Bell 测量 + SQPM}} + \underbrace{\text{离线资源态制备}}_{|\Phi\rangle \text{ 工厂}} \]

Resource-State QRAM 将非 Clifford 复杂度"外包"给资源态制备，在线查询只有 Clifford 操作

查询协议分为三个步骤：

┌─────────────────────────────────────────────────────────┐
│       Resource-State QRAM Clifford 查询流程               │
│                                                         │
│  Step 1: Bell 测量 (深度 O(1))                           │
│  ┌──────────┐    ┌──────────────┐                        │
│  │ QPU 输入  │────│ Bell 测量     │ ← 与 |Φ⟩ 的资源态子集 │
│  │ |ψ⟩ (logN)│    │ → 得到随机结果 m                     │
│  └──────────┘    └──────────────┘                        │
│                                                         │
│  Step 2: 数据加载 (深度 O(1))                             │
│  ┌──────────────┐                                        │
│  │ W_D(m): 根据 m │  条件化的 Pauli-Z 旋转               │
│  │ 条件化数据加载  │  作用于资源态的数据指针 qubit         │
│  └──────────────┘                                        │
│                                                         │
│  Step 3: 逆编码 (深度 O(log N))                           │
│  ┌──────────────────────────────┐                        │
│  │ 自适应 SQPM (X 基 / Z 基)    │  通过 O(log N) 层       │
│  │ 逐层测量并反馈选择下一层基    │  单量子比特测量完成      │
│  └──────────────────────────────┘                        │
│                                                         │
│  输出: |ψ_out⟩ = U_QRAM |ψ⟩                              │
│  全部在线操作: 仅 Clifford + SQPM (零 T 门!)              │
│  查询时间: T_query ≈ 2τ·log N (τ 为中电路读出时间)       │
└─────────────────────────────────────────────────────────┘

为何 Clifford 查询对中科酷原至关重要：

  • 在表面码等主流 QEC 方案中，Clifford 操作可完全横向（transversal）实现，大幅降低纠错开销
  • 非 Clifford 资源（T 门/Toffoli）的离线制备可与查询并行，不占用在线算法时间
  • Bell 测量和 SQPM 是中性原子平台上最高保真度的操作之一（单比特测量保真度 >99.9%）
  • 查询深度仅 2 log N（约为传统 bucket-brigade 的一半）

4.2 QRAM 工厂：中性原子阵列实现

资源态 |Φ⟩ 的制备在专门的「QRAM 工厂」中离线完成。Cesa 等人给出了基于中性原子动态重排的高效制备方案：

│                                                         │
│  阶段 2: 系统重排 (O(1) 全局移动)                         │
│  ┌──┐     ┌──┐     ┌──┐                                 │
│  │●●│ ──→ │ ●│ ──→ │  │    通过相干原子转移               │

│                                                         │
│  阶段 4: 注入 QPU Zone                                   │

工厂周期 T_factory 的估计：

\[ T_{\text{factory}} \approx 3.6 \cdot \tau_T \cdot N^{1/4} + 2\tau \cdot \log N \]

第一项来自原子重排（τ_T ≈ 33 μs 为最小阱距传输时间），第二项来自 SQPM 时间（τ ≈ 500 μs）

对于 N=1024（1KB 存储），\(T_{\text{query}} \approx 13\text{ ms}\)，工厂速率 \(1/T_{\text{factory}} \approx 0.1\text{ kHz}\)。在当前实验参数下，重排时间在 N ≤ 2²⁴ （~2MB）前保持可忽略。

方案二：Bucket-Brigade 原生物理实现

5.1 路由器节点的物理实现

这是最直接的方法：将每个 Bucket-Brigade 二叉树路由器节点对应到一个（或少数几个）中性原子，利用里德堡阻塞门直接执行路由操作。

历史先例：Hong et al. (2012) "A Robust Quantum Random Access Memory" 首次提出了基于里德堡原子的 QRAM 物理实现方案，使用微环形谐振器（microtoroidal resonator）作为光子-原子接口。虽然其光子方案与中科酷原平台不同，但路由器节点的原子态编码和里德堡相互作用机制是直接相关的。

5.2 里德堡阻塞路由协议

中科酷原已有的 ORMD（Off-Resonant Modulated Driving）CZ 门技术可直接推广为条件 SWAP 路由操作：

\[ U_{\text{route}} = |0\rangle_c\langle 0| \otimes \text{SWAP}_{h,0} + |1\rangle_c\langle 1| \otimes \text{SWAP}_{h,1} \] \[ \text{CSWAP} = |0\rangle_c\langle 0| \otimes I + |1\rangle_c\langle 1| \otimes \text{SWAP} \]

路由器操作：控制原子（c）决定保持原子（h）与左子节点（0）或右子节点（1）交换

关键操作序列（每个路由层）：

  1. 地址注入：将地址 qubit 原子转移到路由器的控制位
  2. 里德堡阻塞 CSWAP：基于控制态，条件交换数据原子与左或右子节点
  3. 解纠缠：逆操作回退控制原子与数据原子之间的纠缠

5.3 三能级 vs 二能级路由器

Lee/Mehta et al. (2024) 的噪声分析揭示了路由器能级结构对 Noise Resilience 的重要影响：

路由器类型状态保真度缩放硬件需求
三能级 (推荐) |W⟩ (等待), |L⟩ (左), |R⟩ (右) \(1-F \in O(n^2)\) 需要 qutrit 编码；闲置态 |W⟩ 抑制了误差传播
二能级 |0⟩-初始化 |0⟩ (默认左), |1⟩ (右) \(1-F \in O(n^3)\) 简单 qubit 编码；但误差沿默认路径传播更远
二能级任意初始化 任意态 \(1-F \in O(n^3)\) (查询倍增) 需查询倍增(Q²=1)，深度翻倍，保真度缩放降级

对中科酷原的建议：使用三能级路由器编码。可通过以下方式实现 qutrit：(a) 两个超精细能级 + 一个里德堡能级作为 |W⟩；(b) 两个相邻原子共享编码一个路由器（一个编码控制态，另一个作为辅助），利用里德堡阻塞保持 |W⟩ 态的高保真度。

方案三：混合 QRAMpoly + 中性原子

论文：Mukhopadhyay (2025) "A quantum random access memory (QRAM) using a polynomial encoding of binary strings" (arXiv:2408.16794)

QRAMpoly 使用布尔串的多项式编码替代二叉树路由，实现了 T-depth 的指数级降低。虽然原始设计为 Clifford+T 电路，但其核心思想可以映射到中性原子平台。

QRAMpoly 的核心创新：

\[ (b_1, b_2, \ldots, b_n) \mapsto p_b(x_1, \ldots, x_n) = \prod_{i=1}^n \left(\frac{1+(-1)^{b_i}}{2} + x_i\right) \] \[ p_b(b'_1, \ldots, b'_n) \equiv \delta_{b,b'} \pmod{2} \]

多项式的正交性天然实现地址选择：只有匹配的地址使多项式为 1

性能对比：

指标Bucket-BrigadeCSWAPQRAMpoly
T-depthO(log N)O(√N)O(log log N)
T-countO(N)O(√N)O(N - log N)
逻辑量子比特O(N)O(√N)O(N)

QRAMpoly 的 T-depth 为 O(log log N)——对 Bucket-Brigade 有指数级改善！然而，这需要大量的 Toffoli 门（非 Clifford），在容错设置中成本高昂。

在中科酷原平台上的实现路径：

  • 多项式编码可用里德堡阻塞 Toffoli 门（3 原子方案：2 个控制 + 1 个目标）直接实现
  • O(N) 辅助原子的初始化可与魔幻光强阱结合，享受长相干时间
  • T-depth 的指数优势在深度受限的中性原子系统中尤为重要（减少原子加热）
  • 推荐策略：在 Resource-State QRAM 框架下使用 QRAMpoly 的逻辑结构来制备 |Φ⟩——将 QRAMpoly 的 T-gate 复杂度外包到离线工厂

QRAM 错误分析与噪声抑制策略

7.1 Bucket-Brigade 噪声弹性

Lee, Mehta & Jiang (2024, arXiv:2412.10318) 将 Bucket-Brigade 的噪声弹性分析扩展到更接近实际物理平台的场景。以下错误模型均已被证明保持 polylog 保真度缩放：

错误来源物理对应影响缓解措施
空间关联误差 激光束光斑覆盖多个相邻路由器 关联路由器同时出错 光纤阵列独立通道天然抑制关联
相干误差 里德堡激光相位漂移 误差累积而非抵消 Pauli Twirling (见 7.3); 魔幻光强阱抑制光强噪声
初始化误差 查询间路由器未完全复位 误差传播跨查询 查询倍增 (Query Doubling) 保证正确性
去极化噪声 背景气体碰撞、杂散光 连续衰减路由器相干性 真空改善; 动态解耦序列
里德堡噪声 297nm 光生电子引起的电场噪声 里德堡态退相干 电子光脱附 (中科酷原已有方案)

7.2 Error Filtration 协议

Wang et al. (2025, arXiv:2503.13832) 开发了大规模 Bucket-Brigade 模拟器并系统研究了 Error Filtration (EF) 的效果：

\[ \text{EF level } T: \text{ 控制寄存器 } T \text{ qubit, 执行 } 2^T \text{ 次 } U_{\text{noisy}} \] \[ \text{后选择 } |0\rangle^{\otimes T} \text{ 后，保真度缩放: } (1-F) \to (1-F)/2^T \]

EF 以降低成功概率为代价，指数级抑制非相干噪声

Wang 等人的关键发现：

  • 在高噪声/大地址区域，EF 的抑制效果出现"异常"——后选择概率呈指数衰减，严重限制有效抑制倍数
  • 提出精炼 EF 判据：基础保真度必须足够高（F > 0.99），否则后选择概率过低
  • 对于 n=20（N≈10⁶），ε≈10⁻⁴ 时 EF 可将保真度从 ~80% 提升到 ~95%（T=1），但 T=2 时后选择概率仅 ~10⁻³

实用建议：EF 协议最适合于中低噪声 + 中小规模的场景（N ≤ 2¹²，ε ≤ 10⁻⁴）。对于中科酷原当前平台（200 qubit, 双比特门误差 ~1%），EF 可提供 ~2-3× 的保真度提升，但不应被视为大规模 QRAM 的唯一噪声抑制手段。

7.3 相干误差的 Pauli Twirling

Lee/Mehta et al. 还提出了针对 QRAM 的专用 Pauli Twirling 方案。利用 Bucket-Brigade 计算-逆计算（V_d 和 V_d⁻¹）的对称性：

\[ Q = V_d^{\dagger} \cdot V_x \cdot V_d \] \[ \text{在 } V_d \text{ 和 } V_d^{\dagger} \text{ 之间插入 Pauli 补偿门，将相干误差随机化为随机 Pauli 误差} \]

该方案虽然不能直接 twirl 每个单独的路由门（因为路由操作包含非 Clifford 的 CSWAP），但可以在正向路由和逆向路由之间整体施加补偿，利用了 Bucket-Brigade 的镜像结构。

这对中科酷原平台特别重要，因为里德堡激光的相位噪声是主要的相干误差来源。

  • 光纤阵列架构为每个路由器节点提供独立、低串扰的控制通道——这恰好解决了 QRAM 最关键的路由器寻址问题，是其他中性原子团队（如 Harvard/QuEra 使用 SLM+AOD 扫描）不具备的优势
  • 异核双物种（⁸⁵Rb/⁸⁷Rb）天然解决路由器和 QPU 量子比特之间的串扰——这在其他平台需要复杂的频率复用方案
  • 室温工作 + 标准机柜使得 O(N) 个路由器阵列的物理部署变得可行，无需像超导平台那样为每个路由器配备稀释制冷机内的布线
  • 相干原子转移的高保真度（0.99992/周期）为 Resource-State QRAM 所需的动态原子重排提供了物理基础
