1. 引言：为什么选择中性原子？

中性原子量子计算是当前最具竞争力的量子计算平台之一。与超导量子比特（需要毫开尔文低温）和离子阱（串扰受限）相比， 中性原子平台具有几个独有的优势：

🔑 六大核心优势：
  • 全同性——同种原子的所有量子比特天然完全相同，无制造差异性
  • 可扩展性——无需低温制冷，可在室温运行；2025年已实现6100+原子的阵列
  • 长相干时间——超精细基态编码的相干时间可达秒级（记录：12.6秒）
  • 动态可重构——光镊可通过AOD移动，实现任意量子比特间的连接
  • 高保真度——单量子比特门 >99.98%，双量子比特门 >99.5%
  • 室温操作——无需稀释制冷机，大幅降低基础设施复杂度

2024年底，哈佛大学 Bluvstein 等人用 280 个物理量子比特编码 48 个逻辑量子比特，首次展示了 纠错逻辑量子比特在算法层面超越物理量子比特，被 Physics World 评为 2024 年度突破。 2025年，Caltech Endres 组进一步将光镊阵列扩展至 6100+ 原子、12,000 个光镊位点， 标志着该平台已进入大规模扩展阶段。

2. 核心物理架构

2.1 原子捕获：光学偶极阱与光镊

光镊的核心物理原理是AC Stark 效应（光学偶极势）。一束强聚焦的远失谐激光照射中性原子时， 交变电场会在原子上感生振荡偶极矩，产生保守势能：

\[ U_{\text{dip}}(\mathbf{r}) = -\frac{1}{2\epsilon_0 c}\,\mathrm{Re}(\alpha)\, I(\mathbf{r}) \]

其中 \(\alpha\) 是原子极化率，\(I(\mathbf{r})\) 是位置 \(\mathbf{r}\) 处的激光强度。 当激光频率 红失谐（低于原子共振频率）时，\(\mathrm{Re}(\alpha)>0\)， 光强最大处形成势阱最小值，原子被吸入并囚禁。

2.2 激光冷却与单原子加载

原子首先需要从室温蒸汽（~300 K，速度~240 m/s）冷却至 μK 量级，才能被浅光镊（~1 mK）捕获。 冷却过程分两步：

步骤 1：磁光阱 (MOT) 冷却

六束圆偏振激光对射，配合四极磁场，利用多普勒效应： 原子向光束运动时，感受到激光蓝移（更接近共振）→ 吸收更多反向光子 → 减速。 三维MOT可将原子云温度降至约100 μK。

MOT 原理（一维简化）： ← 光束₁ (σ⁺, 红失谐 δ<0) 原子 → v ← 光束₂ (σ⁻, 红失谐 δ<0) 多普勒效应：f_atom = f₀(1 ± v/c) → 逆光运动的原子吸收更多光子，受到减速力 F = ℏk·Γ·(散射率差)

步骤 2：偏振梯度冷却 (PGC)

关闭磁场后，利用偏振梯度进一步冷却至~10 μK（亚多普勒冷却）。 原子在空间中感受到周期性偏振变化，每爬升一个光势"山丘"消耗动能。

步骤 3：单原子加载

将光镊阵列置于冷原子云中，原子随机落入阱中。由于光辅助碰撞（碰撞阻塞效应）， 一旦一个原子进入微米级光镊，第二个原子进入时会发生非弹性碰撞导致两者被弹出——保证了每个光镊最多一个原子。 初始加载概率约 50%，通过多次加载和重排可达>99%填充率。

2.3 量子比特编码

量子比特编码在碱金属原子（如Cs-133, Rb-87）的超精细基态能级中。 以铯-133为例：

\[ |0\rangle = |F=3,\; m_F=0\rangle,\qquad |1\rangle = |F=4,\; m_F=0\rangle \]

两个能级之间的频率差为 ~9.2 GHz（铯原子钟跃迁）。 选择 \(m_F=0\) 态是因为它对磁场涨落的一阶灵敏度为零（线性塞曼效应消失）， 二阶塞曼效应主导→超长相干时间。

其他可选的编码方案：

编码方案原子种类特点
超精细基态133Cs, 87Rb最成熟；相干时间~12.6s (Cs, 2025)
核自旋态171Yb核自旋 I=1/2，极长T₂；魔幻光镊兼容里德伯态
光学钟态88Sr窄光学跃迁；天然适用于光晶格钟技术

2.4 阵列生成：SLM 与 AOD

现代中性原子量子计算机使用空间光调制器 (SLM) 将单一激光束分束为数百至数千个独立光镊， 而声光偏转器 (AOD) 用于动态横向移动光镊。2025年的最新方案还引入了 声光透镜 (AOL) 实现三维传输。

3. 单量子比特门操作

3.1 微波/拉曼跃迁原理

在Bloch球表示中，单量子比特门是绕任意轴的旋转。实现方式是 共振微波或拉曼激光驱动超精细态之间的跃迁。 两能级哈密顿量在相互作用表象中为：

\[ H_{\text{1q}} = \frac{\hbar\Omega_R}{2} \big( e^{i\varphi}|\hspace{-1pt}0\rangle\langle1\hspace{-1pt}| + e^{-i\varphi}|\hspace{-1pt}1\rangle\langle0\hspace{-1pt}| \big) + \frac{\hbar\delta}{2}\big( |1\rangle\langle1| - |0\rangle\langle0| \big) \]

其中 \(\Omega_R\) 为拉比频率（正比于驱动场振幅），\(\varphi\) 为驱动场相位（决定旋转轴）， \(\delta\) 为失谐（决定绕Z轴的旋转分量）。

任意单量子比特门构造

在共振条件 (\(\delta=0\)) 下，一个持续时间为 \(t\) 的脉冲产生绕轴 \(\mathbf{\hat{n}} = (\cos\varphi,\sin\varphi,0)\) 的旋转：

Rₓ(θ) = exp(-i θ σₓ/2)：驱动相位 φ=0 的脉冲，持续 t = θ/Ω_R R_y(θ) = exp(-i θ σ_y/2)：驱动相位 φ=π/2 的脉冲，持续 t = θ/Ω_R R_z(θ) = exp(-i θ σ_z/2)：通过虚拟Z旋转（相位累积）实现，无需实际脉冲 任意SU(2)门可分解为： U(α,β,γ) = R_z(α) · R_y(β) · R_z(γ) （Euler角分解）

3.2 相位调制低串扰方案

Wang等人 (arXiv:2310.19741) 提出了相位调制连续驱动方案，解决传统方案中 高功率激光寻址导致的邻位串扰问题：

工作原理：
  • 目标量子比特感受到特定的拉比频率 \(\Omega_{\text{target}}\)
  • 驱动场被相位调制，使驱动频率仅在 \(\Omega_{\text{target}}\) 处共振
  • 旁观者量子比特（具有不同 \(\Omega\)）对驱动场是远失谐的→一阶抑制
  • 传统光移位方案仅提供二阶抑制→本方案串扰显著更低
  • 通过调谐调制参数可实现绕任意轴旋转

3.3 全局与局域寻址策略

策略实现方式优缺点
全局寻址 单一大口径微波/拉曼光束覆盖整个阵列 ✅ 简单、低噪声 ❌ 所有量子比特做同一操作
传输寻址 AOD将目标原子移至独立"门操作区"，施加全局光→移回 ✅ 无光学串扰 ❌ 传输时间随系统规模线性增长

📊 实验基准：2025年Caltech团队的铯原子系统中， 单量子比特门保真度达到 99.9834(2)%（通过全局随机基准测试测量）。 Atom Computing的¹⁷¹Yb系统也达到>99.99%的单量子比特门保真度。

4. 双量子比特门：里德伯阻塞机制

双量子比特纠缠门是中性原子量子计算的核心——也是最具技术深度的环节。 所有主流方案均基于里德伯阻塞 (Rydberg Blockade) 机制。

4.1 里德伯原子与相互作用

里德伯原子是指价电子被激发到极高主量子数 \(n\)（典型值 \(n\sim50-100\)）的原子。 在此状态下：

  • 轨道半径 \(\propto n^2 a_0\) → 对 \(n=70\)，\[r \approx 70^2 \times 0.053\,\text{nm} \approx 260\,\text{nm}\]
  • 偶极矩 \(\propto n^2\) → 巨大的电偶极矩
  • 范德华相互作用 \(V(R) \propto n^{11}/R^{6}\)（非共振情况）
  • 共振偶极-偶极相互作用 \(V(R) \propto n^{4}/R^{3}\)（Förster共振情况）
  • 辐射寿命 \(\tau \propto n^{3}\)（对 \(n=70\)，约100 μs）

以铷-87的 \(n=70\) 里德伯态为例，在间距 \(R=3\,\mu\text{m}\) 时， 范德华相互作用能量约为 \(V/h \sim 2\pi \times 200\,\text{MHz}\)， 远超典型拉比频率 \(\Omega/2\pi \sim 2-5\,\text{MHz}\)。

4.2 里德伯阻塞原理

这是理解所有双量子比特门方案的核心物理图像：

图 4.2：里德伯阻塞的能级结构
原子A 原子B |r⟩ |r⟩ ↑ Ω V(R) ≫ Ω ↑ ✗ 被阻塞！ | ═══════════════ | |1⟩ |1⟩ (由于|rr⟩态能移巨大， 双激发跃迁严重失谐) --------------------------------------------------------- 哈密顿量（相互作用绘景）： H = ℏ Σᵢ [ Ω/2 (|1⟩ᵢ⟨r|ᵢ + h.c.) ] + V |rr⟩⟨rr| 其中 V/h ~ 200 MHz（间距3μm时）≫ Ω/2π ~ 2-5 MHz
🔬 阻塞条件的物理实现：

当两个原子距离足够近（\(R \sim 2-5\,\mu\text{m}\)）时，里德伯-里德伯相互作用 \(V\) 远大于激发激光的拉比频率 \(\Omega\) 和线宽 \(\Gamma\)。 此时，即使两个原子都处于 \(|1\rangle\) 态且被激光同时照射， 双激发态 \(|rr\rangle\) 因巨大的相互作用能移而远离共振， 系统只能在对称叠加态 \(|\Psi_+\rangle = (|1r\rangle + |r1\rangle)/\sqrt{2}\) 和基态 \(|11\rangle\) 之间相干演化。

演化频率从单原子的 \(\Omega\) 变为集体增强的 \(\sqrt{2}\,\Omega\) → 这就是实现受控相位门的物理基础。

4.3 CZ 门方案 I：全局脉冲 π–2π–π（Levine/Fromonteil方案）

这是目前实验上最广泛采用的受控相位门（CZ）方案。 由 Levine 等人 (2019, PRL) 提出，Fromonteil 等人 (2023, PRX Quantum) 系统推导了全系列鲁棒变体。 核心创新：所有脉冲都是全局的（覆盖两个原子），无需单原子寻址。

方案 I（5脉冲序列）

CZ = Uₓ(π/(2√2)) · U_y(π) · Uₓ(π/√2) · U_y(π) · Uₓ(π/(2√2)) 总门时间：T_gate ≈ 10.73 / Ω （对于 Ω/2π = 2 MHz → T_gate ≈ 850 ns）

方案 II（5脉冲序列，增强鲁棒性）

CZ = Uₓ(π/2) · U_y(π/√2) · Uₓ(π) · U_y(π/√2) · Uₓ(π/2) 总门时间：T_gate ≈ 21.45 / Ω 对拉比频率准静态误差的灵敏度：ε⁴（二阶零敏感度）
🔍 单次脉冲的定义：

\(U_x(\theta) = \exp(-i\theta\sigma_x/2)\) 是相位 \(\varphi=0\) 的共振里德伯激发脉冲， 作用在跃迁 \(|1\rangle \leftrightarrow |r\rangle\) 上。 \(U_y(\theta)\) 是相位 \(\varphi=\pi/2\) 的对应脉冲。

关键：脉冲仅在 \(|1\rangle\) ↔ \(|r\rangle\) 之间耦合， \(|0\rangle\) 态完全不受影响（态选择性）。由于 \(|r\rangle\) 的阻塞效应， \(|11\rangle\) 分量的演化路径与 \(|01\rangle, |10\rangle\) 不同 → 累积出 \(\pi\) 的条件相位。

里德伯阻塞CZ门的演化详述

对于四个计算基态，门的效应如下：

初始态 |AB⟩演化过程最终态
|00⟩两个原子均处于|0⟩，不与激光耦合→无演化|00⟩
|01⟩仅原子B参与|1⟩↔|r⟩跃迁，经历完整脉冲序列积累相位π-|01⟩ (全局相位)
|10⟩仅原子A参与|1⟩↔|r⟩跃迁，同上-|10⟩
|11⟩两原子同时参与|1⟩↔|r⟩，但因阻塞效应，系统在{|11⟩, |W⟩=(|1r⟩+|r1⟩)/√2}子空间中演化→累积条件相位-|11⟩

对于|01⟩和|10⟩：单原子拉比频率Ω使其在脉冲序列中经历循环回到|1⟩并累积π相位→得到因子e^{iπ}=-1。

对于|11⟩：阻塞条件下集体拉比频率为√2 Ω，循环路径不同但同样累积π相位→得到因子e^{iπ}=-1。因此整体矩阵为-diag(1,1,1,-1)≅CZ（忽略全局相位）。

从 CZ 到 CΦ（任意受控相位门）

Cϕ 门构造：将方案II后半段脉冲的激光相位偏移 Δφ = ϕ/2 → 产生条件相位 ϕ 而非 π → Cϕ = diag(1, 1, 1, e^{iϕ})

4.4 CZ 门方案 II：Jaksch 原始方案

2000年由 Jaksch 等人（PRL 2000）提出，是里德伯阻塞门的理论基础， 但需要局部寻址。

┌─ 原子A（控制比特）─┐ ┌─ 原子B（目标比特）─┐ |1⟩_A → π脉冲→ |r⟩_A （激发至里德伯态） ↓ |0⟩_B → 2π脉冲→ |0⟩_B （仅在A不处于|r⟩时共振；若A在|r⟩则被阻塞→相位累积π） ↓ |r⟩_A → π脉冲→ |1⟩_A （退激发回基态） 总门时间：~12.57/Ω，保真度灵敏度：ε² 级别（不如Fromonteil方案的ε⁴）
⚠️ 为什么现代实验改用全局方案： Jaksch方案需要对两个原子分别寻址（独立的控制光和目标光），实现复杂度高且容易引入串扰。 Fromonteil的全局方案无需区分控制/目标比特——仅需两个原子足够近（满足阻塞条件）， 对两者施加完全相同的脉冲序列即可，大幅简化实验实现。

4.5 CZ 门方案 III：动态粒子数抑制 (DPS)

Carrasco 等人于2025/2026年提出 (arXiv:2512.07656)，突破了传统方案 对 \(V \gg \Omega\) 的严格依赖。

核心思想：

使用零面积调制光脉冲动态抑制里德伯态的粒子数占据， 同时通过相互作用能积累纠缠相位。

  • 脉冲的零面积特性保证操作结束后里德伯态粒子数为零→避免自发辐射退相干
  • 在任意相互作用强度下有效——不要求 \(V \gg \Omega\)
  • 结合了共振门的速度优势与绝热控制的鲁棒性
  • 纳秒级操作中实现约10⁻³ 的噪声平均非保真度

4.6 CZ 门方案 IV：Floquet 几何纠缠门

孙浩文等人 (Physica Scripta, 2024; arXiv:2405.00471) 提出了一个完全不同的视角： 利用 Floquet 工程构造纯几何纠缠门。

工作原理：
  • 周期性调制基态↔里德伯态跃迁的拉比频率 \(\Omega(t) = \Omega_0 + \Omega_m\cos(\omega_m t)\)
  • 在扩展Floquet空间中定义准能级，利用准能级间的非阿贝尔几何相位（非绝热和乐量子门）
  • 门操作仅依赖于演化路径的几何性质→对动力学噪声天然免疫
  • 因为编码在基态子流形中→受环境干扰影响小

4.7 误差源与缓解策略

误差源物理机制缓解策略
有限阻塞强度 \(V\) 不满足 \(V\gg\Omega\)→双激发分量残留 DPS方案天然兼容；优化脉冲设计；使用更高n的里德伯态
里德伯态自发辐射 \(\tau_{\text{Ryd}}\propto n^3\)，对n=70约100μs→ns门中仍累积概率误差 更快门操作（<100 ns）；更高n值；门序列设计使里德伯分量净为零
拉比频率涨落 激光强度噪声→Ω波动→旋转角度误差 Fromonteil方案II将敏感度降至ε⁴；最优控制脉冲整形
多普勒退相 原子残余热运动→多普勒频移δω 自旋回波序列嵌入门操作；鲁棒脉冲设计
Förster共振串扰 近简并里德伯对态间共振偶极-偶极交换 参数优化（避开共振）；电场调控能级
范德华串扰 非目标原子对间残余相互作用（∝1/R⁶） 原子间距优化；最优控制（GRAPE）脉冲设计

5. 原子传输与重排

中性原子平台区别于其他量子计算平台（超导、离子阱、光子）的最显著特性是 量子比特的物理可移动性——电路运行时可将原子在光镊阵列中动态传输。

5.1 传输原理与实现

AOD 驱动的相干传输：

声光偏转器 (AOD) 通过改变射频驱动频率来偏转激光束→光镊及其携带的原子沿横向移动。 原子在移动过程中始终处于光镊的保守势阱中→传输本身是相干的。

关键参数（Manetsch et al., 2025）：

  • 传输距离：610 μm（已演示）
  • 传输保真度：~99.95%
  • 光镊间转移保真度：99.81(3)%
  • 传输速度：~0.5–1 μm/μs

5.2 分区架构 (Zoned Architecture)

图 5.2：三分区量子计算架构 (Bluvstein et al., 2024)
┌──────────────────┐ ┌──────────────────────┐ ┌──────────────────┐ │ 存储区 │ │ 纠缠/门操作区 │ │ 读出区 │ │ (Storage Zone) │ │ (Entangling Zone) │ │ (Readout Zone) │ │ │ │ │ │ │ │ • • • • │ │ •──• │ │ [成像检测] │ │ • • • • │ ←→│ •──• (量子比特对) │ ←→│ [态判别] │ │ • • • • │ │ •──• │ │ [原子回收/替换] │ │ │ │ │ │ │ │ 高密度存储 │ │ 执行CZ门操作 │ │ 电路中间测量 │ │ 无门操作→无误差 │ │ AOD来回搬运原子 │ │ 及辅助操作 │ └──────────────────┘ └──────────────────────┘ └──────────────────┘

分区架构的关键优势：

  • 存储区无门操作→量子比特在等待期间不退化
  • 仅需在执行CZ门时将目标原子对移至纠缠区→门操作误差不累积到旁观者
  • 读出区可进行电路中间测量而不干扰活跃计算
  • 与量子纠错码天然匹配——稳定子测量需要特定物理连接

5.3 三维传输（2025年突破）

Eindhoven 团队 (Guo et al., arXiv:2510.09398, 2025年10月) 提出了 声光透镜 (AOL) 方案，通过双通AOD配置实现三维任意轨迹的原子传输：

  • 使用两个交叉的AOD实现横向偏转 (x,y)
  • 第三个AOD双通配置实现纵向聚焦调谐 (z)→原子可移出焦平面
  • 仅使用市售AOD和标准光学元件→~30%功率损失
  • 克服了传统AOD快速RF斜坡时的柱面透镜效应
  • 使三维任意连接成为可能

6. 量子态读出与测量

6.1 荧光成像

量子比特状态的读出基于态选择性荧光检测：

步骤：
  1. 照射共振冷却光——处于|1⟩（或特定超精细能级）的原子散射大量光子→在CCD上为亮点
  2. 处于|0⟩的原子不与冷却光共振→不散射光子→呈暗点
  3. 每个原子散射约10³–10⁴个光子→信号远高于噪声阈值
  4. 成像后原子可能被加热→需要重新冷却或替换

6.3 电路中间测量 (Mid-Circuit Measurement)

分区架构允许在不干扰计算区量子比特的同时，将辅助比特移至读出区进行测量。 测量结果通过经典反馈控制电路用于：

  • 量子纠错——稳定子测量与纠错操作
  • 预示型门——通过测量辅助比特预示门是否成功（heralded gate）
  • 原子替换——测量后丢失的原子可重新加载

7.4 混合架构：中性原子+离子阱

Kotochigova 等人 (Phys. Rev. Research, 2025) 提出了创新架构： 光镊中的中性原子作为"信使量子比特"在离子链之间传输量子信息， 执行原子-离子纠缠门（碰撞门或里德伯辅助门）。 理想系统为 Ba⁺–Li，纠缠生成速率 10³–10⁴ s⁻¹， 比光子互联方案快100倍，单芯片可达600量子比特。
